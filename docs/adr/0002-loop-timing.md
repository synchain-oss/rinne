# ADR-0002：环路时序

## Summary (EN)

- **Decision**: address the loop by stream-relative positions, not the host timeline. A delay change crossfades two heads linearly over 40 ms (100 ms leading-edge limit).
- **Consequences**: reported latency is always zero; output is bit-identical however the host chops blocks.
- **Compatibility**: changing delay range, note order, fade lengths, alignment or order criteria is a compat event.

## 状态

已采纳（2026-10-22）。

## 背景

宿主时间线不可信：块长、两端先后与时间戳的有效性都随宿主变化。

## 决定

### 寻址与 D

- 读位 R 与写头 W 只单调前进，差值一律有符号。只读 `[max(validFrom, lineValidFrom), min(pulled, validTo))` 内的帧，越界读成 0。
- 配对或清空时本地延迟线锚在当前 W，每块拉到 W（一圈之内）；混音用块首的 R；上报给宿主的延迟恒为 0。
- `D_min = max(N_prep, N_obs)`，违约块当场计入，超长块（n > 32768）不计入；`D_eff = clamp(D_user, D_min, 4 s × sr)`；写环按 ≤ 8192 帧分段。

### 时值档位

16 档按拍数升序（1/4 拍为 1）：.0625 .0833 .125 .1667 .25 .3333 .375 .5 .6667 .75 1 1.333 1.5 2 3 4，默认下标 10，只能追加，越界下标取默认档。桥契约与预览清单三处逆序，以此为准。D = 拍数 × 60 / BPM × sr，四舍五入。BPM 有效范围 [20, 999]，无效时沿用最后一个有效值；会话里从没有过才按 120，并置 noTempo 提示位。目标与当前相差不足 1 个样本不改；超过 4000 ms 截断并置 clipped 提示位。

### 改 D：交叉淡化与去抖

- 新读头增益 k/L（L = 40 ms），旧读头取 1 − k/L，两路逐样本之和恰为 1；相关信号上等功率会过冲。
- 去抖是前沿式、按样本计的 100 ms 窗口：窗口外的第一次改动在那个样本立即开始（起点可在块中间，与切块无关）；窗口内只留最新目标，到期时与主读头不同则再淡一次。
- 起点起主读头（对外报的 D）就是新读头；估计窗口取较大的 D。新读头的有效起点取旧读头的有效起点与自己首个可读位置中较晚者；晚于后者（旧读头刚重同步）时带 20 ms onset。读头槽（3 个）满时起点顺延到下一块（此时起点随切块）。
- 淡化中遇到重同步：两个读头各自淡出，尾巴格跟读头槽走，不丢。5 ms 内连遇第二次、槽不够第四个读头时，收掉包络最小的（≤ 1/4），末值接 5 ms 线性衰减，不阶跃。起播、换采样率、清域之后 D 直接设，不淡。

### 对齐判据

- m = W − (R + off)，off 是锚定时的偏移；同通道正确摆放时恒为 0。
- 严格模式下 m 连续两次检查不为 0 才重同步；|m| > max(两端声明的最大块长, 8192) 立即重同步。改块长或 Output 晚到一块，m 回到 0，不重同步。

### 逐块状态与证据

- 逐块发布 m、w、off、rs、d（主读头的 D）。
- 错序、导出不一致、起播去抖与采样率不一致的判据见 [ADR-0009](0009-loop-evidence.md)。

### 淡变与复位

- 重同步：旧读头 5 ms 淡出（预拷贝尾巴），新数据起 20 ms onset。断档 5 ms、对端消失 10 ms 淡出。
- 数据不够一个淡出时缩短到恰好用完；写头落后取不到样本时先淡到 0 再补 0。
- 超长块：环路不走；回送块首起 5 ms 淡出，下一块从 0 淡回。
- 起播：旧回送淡出 T = min(5 ms, D_eff)；本地延迟线在沿上复位；DSP 复位点是绝对样本号 s0 + T。
- 容忍模式：10 s 内 ≥ 3 次对齐重同步。两端停用 > 250 ms 清空延迟线；同采样率重 prepare 保持流连续。

## 后果

全部按样本定位：参数恒定时输出与切块逐位无关，起播复位点同理。

## 被否决的备选

- 按宿主时间线寻址：延迟随切块漂移。
- 起播等淡出走完那块才清线：复位点随切块漂移。
