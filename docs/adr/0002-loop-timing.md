# ADR-0002：环路时序

## Summary (EN)

- **Decision**: address the loop by stream-relative positions, not the host timeline; heads only advance, D is clamped.
- **Consequences**: reported latency is always zero; output is bit-identical however the host chops blocks.
- **Compatibility**: changing the delay range, note order, fade lengths, the alignment or the order criterion is a compat event.

## 状态

已采纳（2026-10-22）。

## 背景

宿主时间线不可信：块长随宿主与导出方式变化，两端先后不固定，时间戳只在部分时刻有效。

## 决定

### 寻址与 D

- 读位 R 与写头 W 只单调前进，差值一律有符号（W 越过 2^64、位置为负都如此）。只读 `[max(validFrom, lineValidFrom), min(pulled, validTo))` 内的帧，越界读成 0。
- 配对或清空时本地延迟线锚在当前 W，每块拉到 W（一圈之内）；混音用块首的 R。
- 两端上报给宿主的延迟恒为 0。
- `D_min = max(N_prep, N_obs)`，违约的那一块（n > N_prep）当场计入，超长块（n > 32768）不计入；`D_eff = clamp(D_user, D_min, 4 s × sr)`。「本块是否有界」按块长判，放在块结果里，不进参数面。
- 写环按 ≤ 8192 帧分段，由引擎自己切。

### 时值档位

16 档按拍数升序、严格递增（1/4 拍为 1）：.0625 .0833 .125 .1667 .25 .3333 .375 .5 .6667 .75 1 1.333 1.5 2 3 4，默认下标 10，只能追加。桥契约与页面预览按音符族分组的清单有三处逆序（1/16D、1/8D、1/4D 排在 1/8T、1/4T、1/2T 前），以本表为准。BPM 有效范围 [20, 999]，无效时沿用最后一个有效值，从未有过按 120。

### 去抖

改 D 用 40 ms 线性双读头交叉淡化（两路增益和恒为 1；相关信号上等功率会过冲），目标变化按 100 ms 去抖（按样本计），常量在 `loop/LoopTiming.h`，由时序扩展接入。现在的过渡做法：旧读头 5 ms 淡出、新读头 20 ms onset，读位置不跳变；一次只走一个过渡，没走完时新的 D 先挂着（≤ 约 25 ms）。

### 对齐判据

- Δ = W − R 扣掉锚定时的偏移 off，即 m = W − (R + off)；同通道正确摆放时恒为 0。
- 一次检查 = 写头在这一块动了的那次判据。严格模式下 m 连续两次检查不为 0 才重同步；|m| > max(两端声明的最大块长, 8192) 立即重同步。改块长、Output 晚到一块再补上，m 都回到 0，不重同步。

### 错序判据

- 五个量逐块发布：m（正 = 写头领先）、w、off、rs、d = D_eff。
- 同一周期两端拿同一个宿主时间戳。Input 块首读 Output 槽的时间戳：不小于本块的，说明 Output 已处理本块，记一票；更小则判正确并清零。连续 3 票定为错序。时间戳无效或对端未发布时记 unknown，不猜。

### 淡变与复位

- 重同步：旧读头 5 ms 淡出（预拷贝尾巴），新数据从首个有效位置起 20 ms onset。断档 5 ms、对端消失 10 ms 淡出。
- 判据在拉环之前跑：淡出读到本块拉环后有数据的上界（环在即 W），不取上一块拉到的位置。数据不够一个淡出时缩短到恰好用完；写头落后到主读头取不到样本时，先在剩下的样本里淡到 0 再补 0。
- 超长块：环路不走；回送块首起 5 ms 淡出（不够就缩短），增益块内滑到 0，下一块从 0 淡回。
- 起播：旧回送淡出 T = min(5 ms, D_eff)；本地延迟线在沿上复位（沿后 T 帧之前不再读）；DSP 复位点是绝对样本号 s0 + T。
- 容忍模式：10 s 内 ≥ 3 次对齐重同步（跳变、m 连续两次不为 0）。两端停用 > 250 ms 清空本地延迟线；同采样率重 prepare 保持流连续；`reset()` 只记诊断。

## 后果

全部按样本定位：参数恒定时输出与切块逐位无关，起播复位点也与切块无关。

## 被否决的备选

- 按宿主时间线寻址：延迟随切块漂移。
- 起播在「淡出走完的那一块」才清本地延迟线：复位点随切块漂移，还会把新读头一起作废。
